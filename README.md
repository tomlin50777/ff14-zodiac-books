# FF14 古武天書攻略工具

這是一個非官方、非營利的《FINAL FANTASY XIV》玩家工具，將黃道十二文書、四大黃道任務與星光變石神秘地圖整理在同一個頁面中。

> 本站的攻略資料與圖片並非全部由本站原創。天書流程與地圖主要參考巴哈姆特攻略；星光變石座標與藏寶線索主要參考灰機 Wiki。感謝原作者與各攻略站整理並公開資料，詳細來源列於下方。

## 主要功能

- 整理九本黃道十二文書的副本、FATE、討伐與理符項目。
- 依攻略順序安排討伐與理符路線，並支援單項、單區域、分類及整本完成。
- 書內提供可同步勾選的凍結列，方便邊移動、邊確認尚未完成的副本與 FATE。
- 左側「16 副本」路線整合四大黃道任務、天書重複副本與必要交付階段。
- 四大任務與天書中的相同副本會雙向同步進度。
- 完成狀態保存在使用者自己的瀏覽器中，不需要登入帳號。
- 星光變石依五大區域整理 17 張地圖、34 個可能挖掘點，提供高清線索圖、完整區域路線與目的地小地圖。

## 關於路線與資料正確性

- 天書的討伐與理符順序依巴哈姆特攻略原文整理，目標是減少重複傳送與來回移動。
- 四大黃道任務與天書副本的整合、進度連動及交付提醒，是本站額外整理的輔助功能。
- 星光變石右下小地圖使用核對後的 X/Y 座標定位；線索判讀仍應同時參考右上的原始帶 X 圖。
- 遊戲版本、翻譯或攻略資料可能調整；遇到差異時，請以遊戲內資訊與上方原始來源為準。
