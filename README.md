# FF14 小炮百科

這是一個以實際操作為核心的非官方 FF14 玩家攻略網站。首頁採「冒險者書庫」視覺：每一個攻略主題是一冊不同封面的書，古武為深紅魔導書、金碟為紫色娛樂誌、潛水艇為海軍藍工房航海日誌；打開後的內頁會沿用各自封面的主色與材質語言。古武的四大任務左側頁、單冊任務紙頁、移動路線卡與凍結進度列也統一為酒紅魔導書風格；星光變石地圖區固定採高對比深色地圖室，確保四種主題下都能清楚閱讀。右上角仍可切換晨光白、霧藍、森綠與水晶夜四種明暗環境，選擇會保存在瀏覽器。

網站首頁統一收納不同攻略主題，目前包含：

- **古武攻略**：原有的九本天書、四大任務、副本、FATE、討伐、理符與星光變石地圖工具。
- **金碟遊樂場**：目前顯示「九宮幻卡」與「萌寵之王」兩個主題，分別連至模擬器與圖文攻略。其餘分類暫時隱藏，原始內容保留供之後恢復。
- **潛水艇**：可建立多組工房檔案，每組獨立管理最多四艘船、零件、目標、開圖與目前航程；航海圖以 8 種標記區分已開啟、可開啟、建議路線、1～4 號艇航程與灰色鎖定地點，進度保存在瀏覽器。
- **萌寵之王**：討伐級單人戰圖文攻略，以「準備寵物、倒數部署、分路進攻、中路增援、確認勝利」五個分頁整理人偶與微炸彈打法；支援步驟鍵盤切換、前後步驟、圖片放大與手機排版。
- **幻卡王模擬器**：玩家使用幻卡王完整 7 種可能卡面模擬 NPC，電腦操作新手五張牌並依 55 種局面攻略出牌；棋盤採上排 1、2、3 至下排 7、8、9，方便直接照抄。原表第 9、13、37、39 列的紅色敗局不會用來決定攻略方出牌，命中時改採避敗計算。12 張卡均加入透明中央角色圖案，原有紅／藍卡色與數字配置維持不變。

古武工具的進度記錄與既有功能均完整保留；金碟內容可在不影響古武頁面的情況下持續擴充。

## 潛水艇設定與收船

左側顯示目前工房、船隻和返航狀態；在右欄「本趟／收船」處理出航及收船確認。到時只顯示「預計已返航」，不會自動認定已在遊戲收船；仍須核對出航快照與實際探索地點。沒有出航紀錄時改顯示出航登記入口。

零件可逐部位下拉選擇，也可輸入四碼數字、英文代碼或四個英文名稱。原本的數字映射與順序不變：1/S/Shark 鯊魚、2/U/Unkiu 甲鱟、3/W/Whale 鬚鯨、4/C/Coelacanth 腔棘魚、5/Y/Syldra 希爾德拉；順序為船體、船尾、船首、艦橋，3113 即 WSSW。改型依部位勾選；只有儲存後才更新船隻設定。「系統下一步」統一改稱「系統推薦」，目標計算方式不變。

## 潛水艇探索紀錄與指定地點

「已開啟」表示已發現、可安排前往；「探索過」表示玩家確認本工房有船實際探索過該地點，兩者分開登記。探索紀錄由同工房四艘船共用，不跨工房；舊版沒有這項紀錄，因此空白只代表尚無紀錄，不表示從未探索。可單點或批次補登，也可在確認收船後，依出航當時的可信站點快照自動登記全趟探索紀錄。倒數結束、套用航線或取消航次不會自動登記探索過。只有返航時間而沒有可信航線快照的紀錄，不會推測曾經去過哪些地點。

每艘船可設定「本趟必去」，同趟最多五個地點，必須在同一海域且全部包含於候選航線。指定地點不等於海圖路線從附近經過。推薦會核對已開啟、等級、配裝、航距、單趟航時上限與比較範圍；條件不成立時說明限制，不會省略指定點來產生看似可行的推薦。「省時」在滿足必去條件後選較短航時；「成果」與「效率」仍依選定目的比較。修改計畫不會改寫已出航的快照或遊戲進度。

## 古武攻略

這是一個非官方、非營利的《FINAL FANTASY XIV》玩家工具，將黃道十二文書、四大黃道任務與星光變石神秘地圖整理在同一個頁面中。

> 本工具使用外部攻略資料、遊戲圖像，以及站長親自擷取或提供的遊戲截圖。互動編排、擷取、裁切、向量整理或 AI 清晰化不表示原素材由本站或站長原創。天書流程與地圖主要參考巴哈姆特攻略；星光變石座標與藏寶線索主要參考灰機 Wiki。以下保留既有來源，並區分已知出處與尚未核實的逐圖資訊。

## 主要功能

- 整理九本黃道十二文書的副本、FATE、討伐與理符項目。
- 依攻略順序安排討伐與理符路線，並支援單項、單區域、分類及整本完成。
- 書內提供可同步勾選的凍結列，方便邊移動、邊確認尚未完成的副本與 FATE。
- 左側「16 副本」路線整合四大黃道任務、天書重複副本與必要交付階段。
- 四大任務與天書中的相同副本會雙向同步進度。
- 完成狀態保存在使用者自己的瀏覽器中，不需要登入帳號。
- 星光變石依五大區域整理 17 張地圖、34 個可能挖掘點，提供高清線索圖、完整區域路線與目的地小地圖。
